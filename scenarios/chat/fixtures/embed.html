Example Website

This page simulates an external website that embeds the CalicoDesk Live Chat widget.

It loads the real CalicoDesk installation script (livechat-loader.js) using the URL passed in the loaderUrl query parameter — no credentials, tokens, or secrets are ever stored here.

Welcome visitor

Feel free to browse the site. A chat button will appear in the bottom-right corner once the live chat widget finishes loading.
